# 🌲 Cypress, do Zero à Nuvem ☁️


Sample project to demonstrate a `Cypress, do Zero à Nuvem`.

## Pre-requirements

It is required to have Node.js and npm installed to run this project.

> I used versions `v2.42.1` and `V20.13.1` and 10.8.1 of Node.js and npm, respectively. I suggest you use the same or later LTS versions.

## Installation

Run `npm install` (or `npm i` for the short version) to install the dev dependencies.

## Tests

In this project, you can run the tests on a desktop or mobile viewport.

### Desktop
Run `npm test` (or `npm t` for the short version) to run the test in headless mode.

Or, run `npm run cy:open` to open Cypress App in interactive mode on a desktop viewport.

### Mobile
Run `npm run test:mobile` to run the test in headless mode on a mobile viewport.
